Kudio 1.3.0 · Windows 便携发布版

这是 GPT-SoVITS 的长篇有声书工作台，需要自行准备可正常运行的 Windows GPT-SoVITS 整合包。
支持含 api_v2.py、runtime/python.exe 的目录结构；混合格式音频导出需要 runtime/ffmpeg.exe。
已验证的引擎为 GPT-SoVITS v2pro 整合包，其他版本兼容性需自行试用。
本包不包含 GPT-SoVITS、Python、模型、参考音频或作品数据，不是独立推理引擎。

首次运行
1. 完整解压 ZIP 到可写文件夹（不要在 ZIP 中直接运行），建议放在非系统目录。
2. 双击“启动Kudio.bat”。如果旁边只有一套可用引擎会自动识别，否则弹出目录选择窗口。
3. 选择包含 api_v2.py 和 runtime 文件夹的 GPT-SoVITS 根目录。
4. 浏览器自动打开 http://127.0.0.1:8765/ 。创建作品后，在“声音设置”中
   点击“选择文件”挑选 GPT 模型、SoVITS 模型和参考音频；也可以指定模型文件夹、
   参考音频文件夹并扫描候选文件。填写参考音频原文，选择语言并应用配置。
   模型文件和基础模型必须与使用的 GPT-SoVITS 版本相容。
5. 保存音色预设供其他作品载入；启动语音引擎，等待就绪后生成。

导出与字幕
支持整本 WAV、手动分段 WAV，以及每个生成片段一条的 SRT 字幕。
导出 WAV 自动附带同名 SRT；分段字幕从零开始，按实际音频时长包含段间停顿。
WAV 受 4GB 格式上限约束，超过上限请分段导出。

更换引擎和迁移
退出工坊后双击“配置引擎.bat”，重新选择目录。引擎路径保存在 settings.json。
网页内也可选择 GPT-SoVITS 目录；保存新目录后请重启 Kudio，再启动引擎生成。
作品、预设、音频、日志保存在 data 文件夹。迁移自己的工作时备份整个 data 文件夹。
音色预设和作品中的素材路径为本机绝对路径，换电脑后需重新填写并应用配置。
更改合成参数会使片段重新待生成；只需收听旧音频时无需更改音色配置。
升级前退出程序并备份 data，覆盖程序文件，保留自己的 data 与 settings.json。

分发
可分发这个干净的 ZIP。请勿把自己运行后的整个目录直接打包，避免带入作品及私人路径。
GPT-SoVITS、模型和参考素材需另行获取，并遵守各自的许可和使用授权。

故障排查
路径选择失败：确认选择的是引擎根目录，不是 runtime 或模型文件夹。
窗口报错：保留错误文字，检查目录可写、引擎运行环境完整。
端口占用：访问已有工作台，或先退出已有实例。工坊 8765，推理 9880，训练 9874。
引擎加载失败：展开页面中的“引擎与训练工作台”查看日志。
停止程序请用页面“退出Kudio”；关闭网页不会停止后台生成。
训练由官方界面执行，退出工坊不会终止独立训练任务。

作品管理更新（1.1.0）：作品统一存放在 data/projects/作品名--编号，改名会同步目录名。旧版编号目录在启动时迁移，片段和导出文件原样移动。网页支持将指定作品移入 data/trash 回收站、恢复、输入完整作品名后永久删除。生成中的作品禁止删除。回收站仍占空间，永久删除才清理空间；独立 backups 历史备份不会随之删除。升级前保留整个 data 备份。
